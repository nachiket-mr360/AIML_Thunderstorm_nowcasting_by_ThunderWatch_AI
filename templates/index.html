How to Interpret This Nowcast

Reading the alert and the number above
No thunderstorm alert

The model score for the next hour sits below the locked decision threshold 0.0775. This is a no-alert decision, not proof that no thunderstorm will occur.

Thunderstorm alert

The model score for the next hour reaches or exceeds the locked threshold 0.0775. It is a screening signal for that hour, not a definite thunderstorm forecast.

Next 1 hour

Every value here refers to one future clock hour, t + 1 h, counted from the feature hour shown above. No hour beyond that single hour is predicted.

Probability (model score)

The number is the model's raw score for the positive class. It is deliberately not a confidence and not a calibrated thunderstorm frequency: the model was trained with class weighting, which shifts scores towards the rare class. Read it against the locked threshold, never as a percentage of certainty.

Not an official IMD warning

This dashboard is a research prototype and a decision-support aid only. It is not an official India Meteorological Department thunderstorm or lightning warning and must not be used as one. For official warnings, refer to IMD.

Scale-up / Future Integration

Planned — not integrated

The problem statement covers radar, satellite, lightning and NWP inputs over a spatial grid. The live product on this page currently uses none of them: it is a single-cell, 1-hour nowcast built from provider atmospheric fields. The capabilities below are planned scale-up work, not working features.

  • Radar-derived features Reflectivity and echo-motion predictors from Doppler weather radar.
  • Satellite observations Cloud-top temperature and convection proxies from geostationary imagery.
  • Lightning observations Strike density from ground-based lightning networks as a nowcast predictor.
  • NWP / model fields Numerical weather prediction fields beyond the currently consumed variables.
  • Multi-cell spatial prediction Extending the model from one validated grid cell to a surrounding grid of cells.
